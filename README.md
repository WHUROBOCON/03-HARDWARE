
# WHUROBOCON 硬件组仓库

本仓库为武汉大学 ROBOCON 机器人队硬件组所有电路设计、PCB 文件、硬件文档的集中管理仓库。  
包含本赛季（2027RC）及历史赛季（2026RC）的电源板、驱动板、传感器板等硬件设计定版文件。

## 硬件组介绍

硬件组负责机器人的电路系统设计、PCB 绘制、硬件调试与测试。我们使用 JLC 、keil等工具，注重信号完整性、电源稳定性和可制造性。

**主要职责：**
- 原理图设计与仿真
- PCB 布局布线
- 硬件调试与故障排查
- 元器件选型与 BOM 管理
- 底层驱动开发


## 目录说明

- `docs/` – 文档中心，存放设计规范、选型指南、测试方法。
- `shared/` – 公共资源（常用封装库、原理图符号库）、完整项目，由组长统一管理。
- `2027RC/` – 本赛季项目，各板卡项目自建文件夹，并包含独立的 README.md。
- `2026RC/` – 已结项赛季，归档备用。

## 子项目 README 模板

每个硬件项目（位于 `2027RC/<项目名>/`）必须包含 `README.md`，内容框架如下：

```markdown
